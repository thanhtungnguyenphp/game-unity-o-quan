## Giới thiệu

Ô Quan (Ô Ăn Quan) là game dân gian truyền thống Việt Nam được phát triển trên Unity.

## Tính năng

- ✅ Chơi 2 người (local)
- ✅ Chơi với AI (nhiều độ khó)
- ✅ Tích hợp Gemini AI
- ✅ Bluetooth multiplayer
- ✅ Hệ thống Level & Achievement
- ✅ Daily Rewards

## Yêu cầu

- Unity 2022.3.62f3+
- Android SDK 34+

## Cài đặt

1. Clone repository
2. Mở project bằng Unity Hub
3. Build APK hoặc chạy trong Editor
